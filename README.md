# AURA — Minimalist Next-Gen Mobile Banking PWA

A high-performance, minimalist digital banking progressive web app (PWA) built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

Designed with an architectural black & solid charcoal aesthetic, tactile interactions, responsive layout, interactive 3D cards, live transactions, and offline PWA support.

---

## ⚡ Features

- **Minimalist Charcoal & Black Aesthetic**: Pure matte obsidian `#0B0C0E` and solid charcoal `#141618` design system with zero gradients or flashy color distractions.
- **PWA Ready**: Standalone mobile app installation, custom manifest, and service worker offline caching.
- **Interactive 3D Banking Cards**: Pointer-tracking 3D tilt perspective with frost-freeze card locking and sensitive detail decryption.
- **Precision Spline Analytics**: Timeframe-based financial spline trajectory (1W to 1Y) with interactive hairline data scrubbers.
- **Interactive Floating Capsule Dock**: Ultra-compact hardware pill navigation with spring-physics active tab indicators.
- **Full Banking State Engine**: Multi-account management, send/request/add money flows, transaction filtering, biometric security authentication, savings vaults, and PDF statement downloads.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Documents**: jsPDF
- **Storage**: Persistent Local State & Service Worker Cache

## 🚀 Getting Started
